# Bioresource Technology Submission Package

Priority: 1

Journal: Bioresource Technology

Official guide: https://www.sciencedirect.com/journal/bioresource-technology/publish/guide-for-authors

Submit online: https://www.editorialmanager.com/bite/default.aspx

## Fit

This is the strongest first target because the article combines bioresource technology, biomass pyrolysis, bio-oil characterization, thermochemical conversion, steam reforming, modeling, and data stewardship. The manuscript should be submitted as an original research article, not a pure review.

## Target framing

Use the literature-derived bio-oil database as the source of realistic feed compositions for Cantera simulation. Use the Cantera-generated synthetic reforming dataset, inverse ML model, and soft-sensor/MPC relevance as the main original contribution.

Target title:

Machine-learning soft sensor for bio-oil steam reforming: Cantera-generated data and inverse prediction of bio-oil composition from syngas

## Journal-specific requirements reflected here

- Double anonymized peer review.
- Title page and anonymized manuscript are separate.
- Structured abstract, maximum 250 words.
- 1-7 keywords.
- Highlights required, 3-5 bullets, each maximum 85 characters.
- Graphical abstract required; final image must be made manually, not with generative AI.
- Research article should not exceed 35 pages.
- Maximum 6 figures/tables unless justified.
- Introduction should not exceed 3 pages.
- Conclusion approximately 250 words.
- References alphabetical.
- Data repository deposit and data statement encouraged.
