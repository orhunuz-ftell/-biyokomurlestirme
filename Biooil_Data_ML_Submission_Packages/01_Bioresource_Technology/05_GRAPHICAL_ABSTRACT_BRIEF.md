2. Thermodynamic reforming simulation
   - six surrogate bio-oil groups
   - Cantera reformer
   - T, P, S/C grid
   - 3,150 thermodynamic cases

3. Inverse machine learning
   - syngas + process conditions as inputs
   - MLP 8 -> 128 -> 64 -> 32 -> 6
   - six bio-oil class outputs

4. Soft-sensor and MPC interpretation
   - row-wise R2 = 0.863
   - MAE = 4.03%
