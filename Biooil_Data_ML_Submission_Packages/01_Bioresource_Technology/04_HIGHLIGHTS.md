# Highlights

- Literature bio-oil compositions were converted into Cantera feed inputs.
- Cantera generated 3,150 thermodynamic steam-reforming cases.
- An MLP soft sensor predicted six bio-oil classes from syngas.
- The best model achieved row-wise R2 = 0.863 and MAE = 4.03%.
- The workflow supports future MPC of bio-oil reforming.
