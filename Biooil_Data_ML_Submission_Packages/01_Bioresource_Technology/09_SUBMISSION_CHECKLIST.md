# Submission Checklist

## Required before upload

- [ ] Confirm final author list and order.
- [ ] Confirm corresponding author full contact details.
- [ ] Confirm funding statement.
- [ ] Replace all bracketed placeholders.
- [ ] Create manual graphical abstract image.
- [ ] Deposit data/code package and insert DOI or repository URL.
- [ ] Confirm whether to include secondary-source SQL rows or move them to sensitivity analysis.
- [ ] Run final spelling and grammar check.
- [ ] Verify every in-text citation appears in the reference list.
- [ ] Verify every reference is cited in the text.

## Bioresource Technology checks

- [x] Separate title page prepared.
- [x] Anonymized manuscript prepared.
- [x] Structured abstract under 250 words prepared.
- [x] Highlights prepared as separate editable file.
- [x] Data statement prepared.
- [x] Declarations prepared.
- [ ] Graphical abstract image prepared manually.
- [ ] Figures prepared as separate files at required resolution.
- [ ] Maximum 6 figures/tables enforced or justified.
- [ ] References alphabetized.
- [ ] Manuscript line numbers added in Word before upload if required by Editorial Manager.
