# Graphical Abstract Brief

Energy and AI encourages a graphical abstract. Elsevier policies state that generative AI or AI-assisted tools must not be used to create or alter submitted figures or graphical abstracts. This file is a manual design brief only.

Minimum size: 531 x 1328 px or proportionally larger.

Preferred formats: TIFF, EPS, PDF, or MS Office.

## Proposed layout

Use three panels:

1. Data constraints
   - SQL bio-oil records
   - missing composition fields
   - 30 complete six-target compositions

2. AI inverse model
   - input: T, P, S/C, H2, CO, CO2, CH4, H2O
   - model: MLP
   - output: six bio-oil classes

3. Validation insight
   - row-wise R2 = 0.863
   - group holdout reveals domain limits
   - soft sensor must be uncertainty-aware

## Recommended style

Clean vector diagram with no external images. Use project-derived metrics only.
