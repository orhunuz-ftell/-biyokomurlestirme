# Fuel Processing Technology Submission Package

Priority: 3

Journal: Fuel Processing Technology

Official guide: https://www.sciencedirect.com/journal/fuel-processing-technology/publish/guide-for-authors

## Fit

This is the safer technical alternative. The manuscript should emphasize steam reforming, syngas quality, hydrogen-oriented fuel processing, and process monitoring. The data-availability section should be shorter and used mainly to justify why a soft sensor is needed.

## Target framing

Use the manuscript as a fuel-processing soft-sensor article:

Fuel-processing soft sensor for bio-oil steam reforming: data-curated inverse prediction from syngas

## Journal-specific requirements reflected here

- Single anonymized peer review.
- Editable source files required.
- Abstract maximum 250 words.
- Highlights required, 3-5 bullets, each maximum 85 characters.
- Graphical abstract encouraged.
- Primary research papers and theoretical papers are within the article types.
- Dataset references should include repository, version, year, and persistent identifier where available.
